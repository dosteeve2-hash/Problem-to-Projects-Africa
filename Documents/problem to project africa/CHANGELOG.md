## 🔄 Release Process

1. **Branch**: Create feature branch from `main`
2. **Develop**: Implement features with tests
3. **PR**: Create pull request with description
4. **Review**: Team review & feedback
5. **Merge**: Squash & merge to `main`
6. **Deploy**: Vercel auto-deploys
7. **Tag**: Create release tag (v0.x.x)
8. **Notes**: Add to changelog
