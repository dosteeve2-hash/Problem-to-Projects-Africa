# Problem to Project Africa

Product scaffold for the MVP focused on Burkina Faso.

## Current stack
- Next.js 16 App Router
- TypeScript
- Tailwind CSS v4
- React 19

## Current status
- founding blueprint available
- MVP PRD available
- initial app scaffold created
- landing page, mode selection, adaptive intake form, results page, and dashboard skeleton in place
- Supabase MVP schema added locally in `supabase/migrations`
- recommendation API route and local recommendation engine added

## Run locally
1. `npm install`
2. `npm run dev`

## Next implementation steps
1. Connect Supabase project credentials and auth

4. Add project detail and roadmap dedicated routes
